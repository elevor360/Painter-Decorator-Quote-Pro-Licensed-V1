PAINTER & DECORATOR QUOTE PRO V4 — ELEVOR360D

V4 is the commercial/polished edition of the offline quoting and job-management PWA.

MAIN FEATURES
- Dashboard for quotes, accepted/active jobs, outstanding balances and estimated profit
- Customer database
- Multi-room / multi-area quote calculator
- Paint quantity and tin-cost calculations
- Materials, labour, travel, hire and additional costs
- Markup and optional VAT
- Deposits, payments and outstanding balances
- Quote numbering and job statuses
- Professional printable/PDF quotations and invoices
- Reusable templates
- V4 Quick Job Presets
- Paint colour/finish notes
- Before/after job photos
- Customer approval signature
- Actual expense and profit reporting
- Business branding/settings
- Built-in Help & User Guide
- Backup/restore and protected reset
- Offline/PWA support

INSTALL / TEST
1. Upload the contents of this folder to an HTTPS web host (for example the same hosting method used for your other PWA).
2. Open index.html through the website URL, not by double-clicking the local file.
3. On a supported browser, use Install App / Add to Home Screen when offered.
4. Complete Business Settings before creating customer-facing documents.
5. Download backups regularly. Browser/site data is the app database.

IMPORTANT
V4 stores data locally on the device/browser. Clearing site data can remove records. Photos can use significant browser storage, so keep photo sizes sensible and back up regularly.
