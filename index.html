Help & User Guide

Getting Started

1. Set up your business

Open Settings and enter the trading name, contact details, default markup/VAT and payment instructions used on customer documents.

2. Create a quote

Add the customer, rooms/areas, paint, materials, labour and other costs. V4 calculates the quote as you work.

3. Save and print

Save the quote, then use Print / PDF Quote to print it or choose Save as PDF in your device print window.

4. Run the job

Change the status to Accepted or In Progress, record colours, photographs, expenses, deposits and payments.

5. Invoice and backup

Convert completed work to an invoice and regularly download a backup from Settings.

Important Data Note

This app stores business data on this device. Clearing browser/site data can remove it. Use Backup & Restore regularly, especially before changing phones or computers.
